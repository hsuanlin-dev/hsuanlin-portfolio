# EZSIGN — 為 B2B 簽署流程打造的信任驅動 UI

![image](/ezsign.png)
> **Project Link:** [https://ezsign.tradevan.com.tw/APESP/](https://ezsign.tradevan.com.tw/APESP/) ↗

## 專案背景

我負責 EZSIGN（B2B 電子簽章平台）的前端視覺與互動實作，包含多步驟 Wizard 導入流程與 Landing Page。除了前端實作之外，我也從零建立平台的品牌識別，包括 Logo（後續正式註冊為商標）與完整的色彩系統。底層業務邏輯與功能則由團隊中的其他工程師負責。

## 核心挑戰

電子簽章的導入流程無法簡化成單一表單：使用者需要先上傳文件，再設定一位或多位簽署人的順序，最後配置通知偏好。如何將這些彼此相關的設定拆解成清楚、循序漸進的流程，同時避免使用者一次面對大量資訊，是這個專案的核心 UX 挑戰。
技術選型則有既定限制 — 專案原本採用 Bootstrap，因此並非從零選擇前端框架。我的工作是在既有架構上重新建立整套視覺語言，透過色彩、元件與介面層級的重新設計，讓一個法律性質濃厚、涉及敏感文件的 B2B 流程，呈現出值得信任且專業的產品形象。

## 實際做的事

- 設計並實作多步驟 Wizard 流程，從基本資料、文件上傳，到簽署人與通知設定，將複雜的設定拆解成循序漸進的步驟，降低使用者一次面對大量資訊的負擔。
- 從零建立平台品牌識別，包括 Logo（後續正式註冊為商標）與完整色彩系統，並在既有 Bootstrap 架構下重新設計整體視覺呈現。
- 設計並實作平台 Landing Page，讓訪客進入網站後能快速理解 EZSIGN 的服務內容、使用情境，以及為什麼選擇關貿網。

## 成果

Wizard 導入流程、品牌識別與重新設計後的介面皆已正式上線，成為 EZSIGN B2B 使用者導入體驗的一部分。所設計的 Logo 也已正式註冊為商標，成為公司品牌資產的一部分。
