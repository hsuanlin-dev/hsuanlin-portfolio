# 台北通 — 城市級數位生態系的設計與實作橋樑

![image](/taipeipass.png)
> **Project Link:** [https://id.taipei/tpcd/](https://id.taipei/tpcd/) ↗

## 專案背景

參與台北市政府數位生態系中的多個獨立系統開發——台北通、內部評選平台、無紙化流程、零信任存取入口，分別由不同團隊、在不同時期建置而成，其中包括從零打造的「我的證書」功能。這些系統看似各自獨立，背後卻有一條共同的準則貫穿：全部依循市府設計團隊制定的同一套設計規範，維持一致的藍綠色配色與 Logo 識別，並符合同一套 WCAG 2.1 AA 無障礙標準。

## 核心挑戰

這些系統彼此互不相通，但對市民或內部使用者而言，無論使用哪一項服務，都期待感受到一致的介面、一致的操作邏輯、一致的無障礙體驗——市府設計團隊對 pixel-perfect 還原度的要求也毫無妥協空間。真正棘手的地方在於，各系統的技術選型從一開始就不統一，實際採用的框架與工具視個別專案當下的狀況與對接部門需求而定；唯一能把這些系統串連起來的，只有同一套 Figma 設計規格與無障礙標準，並沒有共用的程式碼可以依循。

## 實際做的事

- 與北市府設計團隊密切合作，將 Figma 規範精準轉化為 pixel-perfect 的正式上線程式碼——這是北市府最重視的品質標準，實作上依專案性質分別採用 React 或 Bootstrap 等不同技術棧
- 在每個約 5 人規模的團隊中，落實共用設計規範的元件實作與 WCAG 2.1 AA 無障礙模式
- 成為團隊中處理前端畫面與無障礙邊界案例的主要諮詢對象，同事遇到相關問題時會直接向我確認

## 成果

從台北通、無紙化流程到零信任存取，這些系統雖然出自不同團隊之手，體驗上卻渾然一體，看不出分野，一致的視覺語言、一致的精緻度、一致的無障礙標準。
