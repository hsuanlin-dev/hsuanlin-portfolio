## Overview

I worked on several digital services within the Taipei City Government's digital ecosystem, including TaipeiPASS, an internal evaluation platform, paperless workflows, and a Zero Trust access portal. These products were developed by different teams at different times, using different technologies. I also built the My Certificates feature from the ground up.
Despite the differences in technology and ownership, all of these products followed the same design system and accessibility standards defined by the city's design team. This included a consistent visual language, blue-green branding, and WCAG 2.1 AA compliance.

## Challenge

The challenge wasn't simply implementing a Figma design—it was consistently translating the same design language into production across completely different tech stacks.
Each project had its own technical constraints and requirements, so there was no shared codebase or component library we could rely on. Some projects used React, while others used Bootstrap or different frontend approaches.
What connected them was the design system and accessibility requirements. My job was to make those standards work in practice, regardless of the underlying technology.
The Taipei City Government's design team also had a strong focus on pixel-perfect implementation, so small differences in spacing, typography, interaction states, and responsive behavior mattered.

## What I Did

- Worked closely with the Taipei City Government's design team to turn Figma designs into pixel-perfect, production-ready interfaces.
- Implemented the same design patterns across different projects and tech stacks, including React and Bootstrap.
- Applied WCAG 2.1 AA accessibility practices and handled accessibility edge cases during implementation.
- Built the My Certificates feature from scratch.
- Became one of the team's go-to people for frontend UI details and accessibility questions, helping teammates resolve edge cases and implementation issues.
- Worked within small teams of around five people, collaborating closely with designers, developers, and stakeholders.

## Outcome

Although these products were built by different teams using different technologies, they ultimately felt like one cohesive digital ecosystem to users.
Across TaipeiPASS, paperless workflows, and the Zero Trust access portal, I helped maintain a consistent visual language, interaction patterns, and accessibility standards—while adapting the implementation to the technical constraints of each project.
